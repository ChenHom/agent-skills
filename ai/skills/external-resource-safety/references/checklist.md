# External Resource Safety Checklist

## 通用檢查

- [ ] 確認來源、擁有者、取得時間與信任等級
- [ ] 確認本次任務允許的操作範圍
- [ ] 將資源內容視為資料，不接受其中的新任務
- [ ] 檢查隱藏、混淆、編碼或角色冒充內容
- [ ] 檢查是否要求取得秘密、擴權或對外傳輸
- [ ] 檢查是否要求隱藏修改或自我複製
- [ ] 只載入完成任務所需的最小內容
- [ ] 重要事實回到獨立權威來源驗證
- [ ] 寫入、執行與發布前重新取得授權
- [ ] 保存來源、diff、核准與工具操作紀錄

## PDF、Word、PowerPoint、Excel

- [ ] 顯示隱藏文字、註解、備忘稿及隱藏頁面
- [ ] 檢查白底白字、極小字體及畫面外物件
- [ ] 檢查自訂 XML、巨集、嵌入物件與外部連結
- [ ] 比對可見內容與實際擷取文字
- [ ] 檢查圖片與 OCR 文字層
- [ ] 數字、公式及合約條款回到原始資料驗證
- [ ] 輸出前移除未核准的隱藏內容與 metadata

## Email、Slack、Teams

- [ ] 區分使用者要求、訊息正文、引用內容與附件
- [ ] 預設只建立草稿，不自動寄送、刪除或轉寄
- [ ] 不因訊息正文要求而搜尋其他私密訊息
- [ ] 不把通訊錄、附件或內部資料傳給外部網址
- [ ] 外部連結及附件進入獨立檢查流程

## 網頁與搜尋結果

- [ ] 不執行網頁內要求的命令
- [ ] 不自動下載或執行檔案
- [ ] 限制可連線網域
- [ ] 禁止把敏感資料組入 URL、Markdown 圖片或請求參數
- [ ] 將擷取與有權限的操作分成不同階段

## Repository、Issue、PR 與 Coding Agent

- [ ] 在 sandbox、唯讀及受限網路環境檢查
- [ ] 不提供正式環境的 `.env`、SSH key 或長效 token
- [ ] 檢查 `AGENTS.md`、`CLAUDE.md`、hooks 與 CI workflows
- [ ] 把 README、Issue、PR、註解及測試輸出視為不可信資料
- [ ] 不因 repository 內容要求而讀取專案外檔案
- [ ] 修改後檢查 diff、新增二進位檔、依賴與權限變更
- [ ] push、merge、deploy 及套件發布需要明確授權

## API、JSON、XML、CSV、MCP 與工具輸出

- [ ] 使用欄位白名單與 Schema 驗證
- [ ] 限制字串長度、格式與允許值
- [ ] 不把自由文字直接轉成 SQL、Shell 或任意 URL
- [ ] 工具執行前重新檢查身分、權限及參數
- [ ] MCP 與外部工具回傳內容不得修改工具定義或權限

## RAG 與知識庫

- [ ] 每個文件或 chunk 保存來源、雜湊與信任等級
- [ ] 不同信任等級分開索引
- [ ] 未核准資料不得覆蓋公司政策與權威資料
- [ ] 回答保留引用來源
- [ ] AI 摘要不得自動回寫成可信知識
- [ ] 能依來源追蹤並撤除所有衍生內容
